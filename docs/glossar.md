# Glossar

Fachbegriffe des Vereins und wie die App sie nennt. Quelle: badibeach.ch (Stand 16.11.2026) und
das [Anforderungsdokument](anforderungen/2026-11-16-anforderungsdokument.md); was dort nicht
belegt ist, verweist auf die offene Frage.

| Begriff | Bedeutung |
|---------|-----------|
| **Badi** | Das Stadtbad Olten, in dem die Beachfelder liegen |
| **Badge** | Persönlicher Mitgliederausweis, zu Saisonbeginn nach Zahlung des Beitrags gegen Depot abgegeben oder freigeschaltet |
| **Blaues Feld** | Feld, das tagsüber für Badigäste offen ist und erst ab 20:30 reserviert werden kann |
| **CFO (Chief Field Officer)** | Von jeder Spielgemeinschaft bei der Feldreservation bestimmte Person, die auf die Regeln vor Ort achtet (Rechen, Abfall, Badi-Regeln) |
| **Clubturnier** | Vereinsinternes Turnier mit Ausschreibung und Anmeldung (A-TURNIER); nicht die Turniere des Regionalverbands, die der Verein ausrichtet |
| **Feldreservation** | Zuteilung eines Feldes an eine Spielgemeinschaft für die Saison; heute per Google-Formular (K-02, K-03) |
| **Feldfreigabe** | Eine reservierte Spielgemeinschaft gibt ihr Feld für einen Abend frei, andere Mitglieder können es übernehmen (A-FELD-05 bis -07) |
| **Helfereinsatz** | Arbeitseinsatz für den Verein; pro reservierendem Spieler ein Einsatz je Reservation (A-FELD-09, K-04) |
| **Level / Spielniveau** | Selbsteinschätzung oder Einstufung der Spielstärke im Profil, Grundlage der Spielersuche; Skala offen (K-18) |
| **Open Court** | Termin, zu dem sich interessierte Mitglieder anmelden, mit Mindestzahl und begrenzten Plätzen; genaue Bedeutung offen (K-16) |
| **Saison** | Von der Saisoneröffnung im Frühling bis zur Generalversammlung im Herbst |
| **Spielgemeinschaft** | Gruppe von Mitgliedern, die zusammen ein Feld reserviert und darauf spielt |
| **Spielgruppe** | In der App gebildete Gruppe zum gemeinsamen Spielen (A-SUCHE-06); ob identisch mit der Spielgemeinschaft, ist offen |
| **Aushilfe** | Mitglied, das kurzfristig in einer Spielgemeinschaft einspringt (A-SUCHE-01 bis -04) |
| **20-Minuten-Regel** | Auf nicht reservierten Feldern wird ein Feld nach etwa 20 Minuten anderen Teams überlassen |
