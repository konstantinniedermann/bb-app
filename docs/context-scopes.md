# Context-Scopes

Welche Pfade bei welcher Aufgabe geladen werden. Solange es keinen Code gibt, ist die Tabelle kurz.

| Aufgabe | Relevante Pfade | Nicht nötig |
|---------|-----------------|-------------|
| Anforderungen klären, Antworten einarbeiten | `docs/anforderungen/`, `docs/abklaerungen.md`, `docs/glossar.md` | `docs/adr/` (ausser die ADR, auf die eine Frage verweist) |
| Architektur, Übernahme aus MyTCO | `docs/adr/`, `docs/anforderungen/anforderungen.md`, `docs/abklaerungen.md`; aus der tco-app nur `README.md`, `docs/adr/` und `docs/abklaerungen.md` | `intern/` |
| Arbeitsweise | `CLAUDE.md`, `docs/beobachtungen.md`, `docs/context-scopes.md` | `docs/anforderungen/` |
